# Cosmoverse / 0110

A local cinematic Next.js experience built from `masterPrompt.txt` and the supplied art and narrative journals. Nothing is hosted or deployed.

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000). For a production preview:

```bash
npm run build
npm start
```

## The expedition

- Layered AstroMech hero, animated SVG identity and planet emblems, and GSAP entrance/parallax animation.
- Interactive Cosmae orbital map and an eight-world atlas with overview, planetary data, terrain composition, landmarks, travel notes, and original illustrated journals.
- Dedicated scroll-pinned 3D exhibits for AstroMech, Ark 11, and the Amethyst cluster, using the supplied GLB models. Drag to orbit; scroll to advance the model and system notes.
- Four canvas sequences: Ark 11 flyby, ship disassembly, exotic-material discovery, and the cockpit.
- Optional Cosmae flyby film, chapter navigation, scene-skip links, keyboard-accessible dialogs and tabs, responsive layouts, and a motion toggle that respects the device's reduced-motion preference.

## Ground truth and assets

`lib/worlds.ts` condenses the supplied `public/narrative/` journals. These fictional records are the source of truth for the planetary data. Each planet exposes its original journal in the atlas. The eight-world system is nested within the larger Cosmoverse.

Artwork comes from `public/backgrounds/`, `public/isolatedAstroMech/`, and `public/webDesignTemplates/`. The existing green `EarthysBackgroud.png` variant illustrates Terraverde because no separate Terraverde background was supplied. The filenames retain their original spelling.

The supplied assets remain unchanged. `public/optimized/` contains WebP derivatives, generated by:

```bash
node scripts/prepare-assets.mjs
```

The script samples every other sequence frame (including the final frame), preserves ordering, and writes `lib/sequences.json`. The four sequences total 259 frames, approximately 9.5 MB. The browser maintains a bounded nearby-frame cache with four concurrent image requests per active sequence. The 3D viewer loads near its section and unmounts offscreen; rendering happens on demand. WebGL or model-loading failures retain an illustrated fallback.

All fonts are bundled locally. No API keys, remote font requests, external HDR files, analytics, accounts, or server-side data storage are required. Metadata uses `http://localhost:3000` as the intended local origin.

## Project layout

- `app/page.tsx` — expedition, hero, navigation, motion orchestration, and film dialog.
- `app/components/world-atlas.tsx` — planet selection, accessible tabs, and field journals.
- `app/components/universe.tsx` — interactive solar-system map.
- `app/components/model-stage.tsx` and `model-viewer.tsx` — pinned exhibits and React Three Fiber rendering.
- `app/components/scroll-sequence.tsx` — bounded image loading and scroll-controlled canvas playback.
- `lib/worlds.ts` — structured lore; `lib/sequences.json` — generated sequence manifest.
- `app/globals.css` — visual design and responsive rules.
